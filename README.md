# Карточки товаров

Небольшое учебное React-приложение для практики нескольких состояний в одном компоненте.

## Возможности

- Компонент `ProductCard` получает название, цену и категорию товара через props.
- Кнопки `+` и `−` изменяют количество; оно не опускается ниже нуля.
- Кнопка «Показать информацию» показывает или скрывает категорию.
- На странице отображаются три независимые карточки. У каждой свои `count` и `isVisible`.

## Запуск

Требуется установленный Node.js и npm.

```bash
npm install
npm run dev
```

Откройте адрес, указанный Vite в терминале.

## Production-сборка

```bash
npm run build
npm run preview
```

## Структура

- `src/App.jsx` — компонент `ProductCard` и список товаров.
- `src/App.css` и `src/index.css` — стили приложения.
- `src/main.jsx` — точка входа React.
- `index.html` — HTML-шаблон Vite.
